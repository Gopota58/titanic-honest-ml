Честное поднятие public leaderboard на классическом датасете Kaggle Titanic (891 обучающих / 418 тестовых) безо всякой утечки меток. Финальный результат — 0.82057 на публичном LB (честный рекорд; «жёсткий потолок» 0.81100 пал 2026-09-13, затем 0.81578 пал 2026-09-16).

Единственный честный арбитр качества здесь — реальный Kaggle public LB. Любая локальная валидация (cross-validation, holdout, даже синтетика с известной истиной) систематически лжёт из-за семейной структуры выборки и covariate shift.

Кампания 2026-09-13: потолок побит (0.81578) — инженерия фичей

Движок C2 воспроизведён, но базовая фича Age вместо грубой глобальной медианы заполнена медианой по группе Title×Pclass (честно, только по train). Кандидат att_N3_ageimp.csv отличается от C2 ровно на 2 строки и дал на реальном LB 0.81578 — потолок 0.81100 пал честной инженерией фичей.

Кампания 2026-09-16: потолок 0.81578 побит (0.82057) — комплементарный сигнал

Движок N3 воспроизведён, но к base-фичам добавлен комплементарный family-survival по ПРЕФИКСУ БИЛЕТА (fs_tp) как дополнительная фича ко всем 3 ключевым моделям — отдельно от основного сигнала по точному билету. Победная конфигурация (att_px_tp, 0.82057)

  • RandomForest, 3-ключевой cv-взвешенный бленд (nm_ticket + ticket + lastname)
  • базовые фичи + Age, импутированная медианой по Title×Pclass + сглаженный OOF family-survival (alpha=10) + комплементарный family-survival по префиксу билета (fs_tp)
  • мелкие деревья (depth=10 / leaf=10), test_rate ~0.30

Методология в двух словах

Единственный сигнал, честно обобщающийся на тест, — сглаженный OOF target-encoding выживаемости семьи (family-survival, α=10). Ключ группировки — номер билета (ticket) и его вариации (nm_ticket = lastname|ticket); билет — самый чистый семейный прокси.

Рабочая архитектура: регуляризованные деревья (RandomForest / ExtraTrees), мульти-ключевой бленд с cv-взвешиванием (вес ключа = softmax от его OOF-CV точности), базовые фичи, контроль test_rate ≈ 0.30. Нарушение любого пункта → covariate-shift коллапс.

Как воспроизвести

pip install -r requirements.txt

# 1) Базовый артефакт (ET-бленд, 0.80143):
python src/make_blend.py

# 2) RF-бленд (0.80382):
python src/gen_robust.py          # -> robust_rf2.csv

# 3) Финальный кандидат (0.81100, воспроизводимо diff=0):
python examples/c2_minimal.py       # -> submissions/c2_minimal.csv

# 4) Рекорд 0.81578 — доимпутация Age (воспроизводимо diff=0):
python examples/n3_ageimp.py        # -> submissions/n3_ageimp.csv

# 5) НОВЫЙ рекорд 0.82057 — комплементарный family-survival (diff=0):
python examples/px_tp.py           # -> submissions/px_tp.csv

# Отправка на Kaggle (требует KAGGLE_USERNAME / KAGGLE_KEY):
python -m kaggle competitions submit -c titanic -f submissions/att_px_tp.csv \
  -m "RF 3-key cvw + Age Title x Pclass + complementary ticket-prefix family-survival, public LB 0.82057"
