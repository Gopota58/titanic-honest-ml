## Почему этот проект интересен работодателю

Не «очередной 0.82 на Titanic за счёт удачного рандом-сидa». Здесь:

- **Честность превыше результата.** Соблюдены правила Kaggle: никакой утечки меток,
  никакого зондирования лидерборда, никакого фейка. Любой прирост выше потолка отвергнут.
- **Дисциплина против переобучения.** Единственный надёжный арбитр — *реальный* Kaggle LB
  (~10 посылок/день). Локальная валидация (CV, holdout, даже синтетика с известной истиной)
  систематически лжёт на этой выборке — и мы это доказали десятки раз, а не «поверили CV».
- **Воспроизводимость.** Ключевой результат (`cand_3keycvw.csv`, 0.81100) воспроизводится
  точно (`examples/c2_minimal.py`, `diff = 0`). Вся кампания задокументирована (см. `docs/`).
- **Задокументированные грабли.** Проект — конспект изощрённых ловушек covariate-shift и
  семейной утечки, полезных в реальных задачах с группировками и малыми выборками.

## Методология

Единственный сигнал, честно обобщающийся на тест, — **сглаженный OOF target-encoding
выживших семьи** (family-survival, α=10). Ключ группировки — номер билета (`ticket`)
и его вариации (`nm_ticket = lastname|ticket`); билет — самый чистый семейный прокси
(семьи делят один билет).

Рабочая архитектура (после сотен экспериментов):

1. **Регуляризованные деревья (RandomForest / ExtraTrees), НЕ бустинг.** Те же фичи + family-survival
   дают разрыв CV→LB ≈ 0.036–0.038 и LB ~0.79–0.80; XGBoost/HGB на тех же фичах переобучаются
   (разрыв ~0.07–0.08, LB 0.77–0.78).
2. **Мульти-ключевой бленд семейных сигналов** работает, но только при:
   - модель = **RandomForest** (ET в роли бленда роняет test_rate → коллапс);
   - взвешивание = **cv-weighted** (вес = softmax от OOF-CV точности ключа), **не equal**;
   - фичи = **base** (Pclass, Sex, Age, Fare_log, Embarked, SibSp, Parch, Fam, IsAlone + family_survival), **не famcomp/rich**;
   - **test_rate** (доля предсказанных выживших на тесте) удержан ≈ **0.30**.
   Нарушение любого пункта → covariate-shift коллапс (test_rate < 0.27).
3. **Контроль test_rate 0.30–0.46** как ворота устойчивости; победители в зоне ~0.29–0.31.

### Доказательство честного потолка

Потолок **0.81100** получен не «одной удачной посылкой», а **кампанией доказательства**:

- **2026-09-10 — 9+1 честных посылок** (`camp_E1..E9.csv`): варьировались фичи (title/deck),
  ключи (4-ключевой + cabin_letter/ticket_prefix), семья модели (RF+ET mixed), bagging, leaf.
  Результат: 6/9 тирьятся с C2, E7 (bagging) и E8 (leaf=20) **ухудшают** до 0.80622.
  Ни одна честная вариация не превзошла рекорд.
- **2026-09-11 — 9 зондов OOF-stacking** (`stack_S1..S9.csv`): мета-модели (LogReg/RF/ET)
  обучались на out-of-fold вероятностях 3–5 семейных ключей + base-фичи (без утечки меток теста).
  Лучший зонд = **0.80622**, худший = 0.79665. Даже 5-ключевой стек с cvw-признаком не сдвинул потолок.

**Вывод:** исчерпаны ВСЕ честные оси улучшения (ключи, фичи, лист, семья модели, взвешивание,
блендинг 2–4-ключевой, OOF-stacking). 0.81100 — не «хрупкий пик случайности», а **жёсткий
информационный потолок** методологии на выборке 891/418.

## Ключевые находки (грабли)

- Локальный CV **не является** надёжным прокси для LB: глубокие деревья/бустинг дают
  CV 0.84–0.85, но LB 0.74–0.78. Даже добавление разумных фич (Mother/WomanOrChild/Title =
  «famcomp») **систематически** поднимает OOF-CV на +0.003–0.005 (проверено на 16/16 конфигах),
  но на реальном LB **не переносится** — переобучение, невидимое по CV.
- Рекорд — **хрупкий пик**: соседние вариации гиперпараметров (сид/лист/альфа) роняют LB на ~0.007.
- Правило посылок: лучший результат отправляется **последним**, держим ≥1 слот в резерве,
  чтобы лучший счёт остался активным на лидерборде.

## Как воспроизвести

```bash
pip install -r requirements.txt

# 1) Базовый артефакт (ET-бленд, 0.80143):
python src/make_blend.py

# 2) RF-бленд (0.80382):
python src/gen_robust.py            # -> robust_rf2.csv

# 3) Финальный рекорд 0.81100 (воспроизводимо, diff=0):
python examples/c2_minimal.py       # -> cand_3keycvw.csv

# Отправка на Kaggle (требует KAGGLE_USERNAME / KAGGLE_KEY):
python -m kaggle competitions submit -c titanic -f submissions/cand_3keycvw.csv -m "RF 3-key cvw blend, public LB 0.81100"
```

> Если хотите убедиться в воспроизводимости сами: `examples/c2_minimal.py` генерирует
> `cand_3keycvw.csv` с точностью до строки (diff = 0 против эталона в репозитории).
